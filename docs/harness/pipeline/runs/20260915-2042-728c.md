## 서술

### 문제

사용자가 '/feature must 다음 작업 확인 후 진행해줘'로 다음 Must 작업을 스스로 찾아 진행하라고 요청했다. 요청 원문에 구체적 범위가 없어 00-triage가 unclear로 판정, 사람이 조사 결과(PRD 리스크 절 권장 순서상 FR-009 다음은 FR-010·FR-011)를 근거로 profile=normal과 범위를 확정했다.

### 원인

FR-010(검수→승인, 브랜드 예시 등록 포함)·FR-011(검수→반려, 사유 필수)이 아직 미구현이었고, 둘 다 FR-009가 만든 상태기계(content-workflow.ts의 TRANSITIONS/transition())에 approve/reject 액션을 추가하는 동일 구조라 한 런으로 묶었다.

### 해결

01-plan에서 2라운드 만에 critical 1건(승인/반려 시 submittedAt 유실 위험)·major 1건(brandExamples insert가 서비스의 'throw 안 함' 불변식을 깰 위험)을 수리해 수렴시켰다. 02-cross-verify(xv)가 새 major 1건(반려 후 재제출·승인 시 rejectReason이 안 지워져 UI에 stale한 반려 사유가 남는 결함)을 추가로 찾아 계약 작성 시 반영했다. 03에서 계약을 메인이 직접 쓰고 impl·test 역할을 병렬 실행했다. 05-code-review에서 arch 리뷰어가 major 1건(잘못된 JSON 바디가 fail() 봉투를 우회)을 냈고 수리했다. 그 리뷰어가 델타 재리뷰에서 같은 계약불일치 지적(resolveActorUserId가 계약상 비공개인데 export됨)을 minor에서 major로 재상정하면서 review_repair 예산(2/2)이 소진돼 에스컬레이션됐다 — 사람이 '이대로 진행'을 선택했고, 실제로는 한 줄(export 제거)짜리 수리라 메인이 직접 고쳐 해소를 확인했다.

### 결과

PR #12(feat-fr-010-011-approve-reject → main)를 생성했다. 05는 4개 리뷰어(gen·data·sec·arch) 전원이 3라운드에 걸쳐 완주했고 최종 열린 Critical/Major는 0건이다. 07 내장 리뷰(medium, 04·05 수리 이력 + 감사 런이라 강제)는 새 major/critical 없이 minor 7건(대부분 기존 코드베이스에 이미 있던 근사·중복 패턴의 연장, 신규 회귀 아님)을 냈고 전부 지연 처리해 PR 코멘트로 게시했다. 완료 등급은 PASS_WITH_GAPS(e2e·docs 스테이지 부재, 어댑터 unverified — 이 스택에 원래 없는 것들).

### 배운 점

요청 예산(파일 10·줄 1500)을 넘는 실제 작업(승인+반려 API, 13파일/1500+줄)은 사람이 사전에 스코프를 확인해야 매끄럽게 진행된다. 또한 05의 review_repair 예산은 '심각도가 라운드마다 바뀌는 재상정'에 취약하다 — 같은 지적이 minor에서 major로 바뀌며 재수리 기회 없이 예산을 소진했다. 사소한 수리(한 줄)라면 메인이 직접 개입해 막힌 상태를 풀 수 있다는 것도 확인했다.

### 계약이 어디서 부족했는가

계약은 API_SPEC.md·PRD.md와 사전에 완전히 일치해 계약 자체를 신규 작성할 필요는 없었지만, 01 플랜 리뷰(2라운드)와 02 xv가 각각 잡은 세 결함(submittedAt 유실, brandExamples 예외 전파, rejectReason 미초기화)은 모두 계약 작성 시점에야 반영됐다 — 더 이른 단계(01 1라운드)에서 실제 코드(content-workflow.ts의 updatedRow 삼항식)를 더 꼼꼼히 대조했다면 한 라운드로 끝났을 수 있다.

### 05 리뷰 범위가 적절했는가

05는 4명(gen·data·sec·arch) 전원 참여해 계약의 전 영역(상태기계·인가·데이터 계층·라우트)을 커버했다. test-quality-reviewer는 profile_caps(normal=4)에 의해 우선순위상 배제됐다 — 이번 PR은 테스트 파일도 상당히 늘었으나(4개 파일 수정/신규) 전담 테스트 품질 리뷰는 받지 못했고, 이는 07의 내장 리뷰(medium)가 일부 메웠다.
